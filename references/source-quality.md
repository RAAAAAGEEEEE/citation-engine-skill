# Qualité des sources — SEO

Voir [SKILL.md](../SKILL.md) pour le résumé.

## Ordre de préférence

1. source primaire officielle
2. documentation officielle
3. publication scientifique
4. organisme public
5. données propriétaires avec méthodologie
6. média reconnu citant sa source
7. étude sectorielle avec méthodologie
8. source secondaire vérifiable
9. contenu d'opinion clairement identifié

## À éviter comme source factuelle principale

- contenu sans auteur
- contenu sans date
- agrégateur sans source primaire
- publication sociale isolée
- contenu généré sans méthodologie
- page conçue uniquement pour l'affiliation
- chiffre recopié sans origine

## Affirmations temporelles

- indiquer une date ISO 8601 ;
- vérifier qu'elle est toujours actuelle au moment de l'audit ;
- préférer la source la plus récente disponible, sans ajouter artificiellement une année ancienne à la recherche.

## Contradictions entre sources

- conserver les deux sources ;
- expliquer la divergence dans le fichier concerné (`audit.md`, `sources.csv`, ou `opportunities.csv` selon le contexte) ;
- privilégier la source primaire ;
- ne jamais masquer l'incertitude — utiliser `[À VÉRIFIER : ...]` si la divergence ne peut pas être tranchée.
